## Ambiguidades do enunciado resolvidas pelo projeto

O PDF não define estes detalhes. Eles foram tratados como decisões, não como exigências atribuídas ao enunciado:

1. código visual derivado como `SOL-000001`, sem coluna própria;
2. paginação `page`/`page_size` e ordem fixa por abertura/ID decrescentes;
3. `ILIKE` sem distinção entre maiúsculas/minúsculas; remoção de acentos não foi acrescentada;
4. sessão absoluta de oito horas, sem renovação;
5. exclusão física, sem histórico/auditoria;
6. edição parcial de título, descrição e categoria;
7. identidade visual simples e acessível, pois nenhum guia/ativo oficial foi fornecido.
